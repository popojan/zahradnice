# EW-7 — the codon table into matter (F4, the last authored mapping)

Date: 2026-08-23, session 11. Registrations: ew-design.md §EW-7
(P7-1..4 + Amendment 8, pre-sweep). Driver: ew7.py; data:
ew7_runs.csv (400 runs, zero exactness failures). Verdict up
front: **the codon table's existence, locality, and persistence
are now matter-side facts.** Translation is gated on a table row;
the frozen rule set holds only the space of mappings. An absent
code is not slow translation but none; a wounded code dies column
by column and takes the world with it; a machine can maintain the
code's universality — for rent.

## Setup

EW-5's kernel world (ring 24, D = w×4 + b×8, 8 Π + 4 Ω,
ε_d 0.005) plus a TABLE row between code and machinery: the
translator reads the codon at (−2,0) and the table glyph at
(−1,0); one execute body per table glyph, headers = that glyph's
mapping. Two tables in frozen law: `1` = {b→Π, w→Ω}, `2` = the
swap (compiled everywhere, on-screen nowhere in these arms — the
mosaic competition, evolution of the code proper, is the
registered next increment). Table-keeper Ξ (immortal, ×2, drift
1.0 per Amendment 8): copies the table glyph east into an emptied
cell. Byte r erases one random table glyph.

## Results (100 seeds/arm)

| arm | survived | builds | repairs | table cells |
|---|---|---|---|---|
| live (uniform code, no r) | 77/100 | 315 | — | 24.0 |
| no-code (empty table row) | 0/100 | **0** | — | 0 |
| wounded (r/4, no keeper) | 2/100 | 128 | — | 0.0 |
| maintained (r/4, Ξ×2) | 57/100 | 218 | 46.4 | 20.4 |

- **P7-1 HELD exactly**: live = 77/100 — the same number as
  EW-5's kernel, and likely the same worlds: with a uniform
  intact table the extra table-gated bodies change no applicable
  set and dry-runs draw no randomness (the OW-9 trigger-filter
  tool one more time). An intact universal code is dynamically
  invisible — which is precisely why its absence and decay are
  the experiment.
- **P7-2 HELD exactly**: zero constructions in 100 empty-table
  runs. Translation without a physically instantiated mapping is
  absent, not degraded — the code is matter or it is nothing.
- **P7-3 HELD**: under table wounds without maintenance the code
  erodes to zero and survival collapses to 2/100; the 128
  early-life builds date the code's death (construction stops
  when the local table cell dies — per-column code silencing).
- **P7-4 HELD, with the rent quantified**: keepers hold the code
  at 20.4/24 under the same wounds and restore survival to
  57/100 — far above the registered half-of-live bar — at a
  20-point rent against live. **Amendment 8's finding en route**:
  at drift 0.1 the maintained arm died 0/5 WITH a perfectly
  repaired code — slow immortal keepers are standing obstacles
  whose parking columns are translator landing slots
  (construction −60%). Keepers must keep moving: maintenance
  machinery is priced not only in slots and lottery share
  (EW-6's law) but in traffic.

## What EW-7 closes, and the residue

The reviewer's summary of the arc's own doctrine was: don't
enrich the substrate — remove the last hardcoded piece. The codon
table was that piece. It is now a row of matter: locally read
(there is no global anything under A1 — even a universal code
must be physically present at every column where it is used),
woundable, and maintainable by a machine whose rent is measurable.
The honest residue, stated plainly: the SPACE of mappings (two
authored tables) remains law-side — per-column code is a choice
among authored tables, exactly as F3's per-locus law was a choice
among authored alleles; the keeper is immortal scaffolding (the
x-codon closure — the code encoding the machine that maintains
the code — is named, not built); and the mosaic table-1-vs-table-2
competition (does selection freeze the code? Crick's frozen
accident as a pre-registerable question) is the arc's next
opening.
