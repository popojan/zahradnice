# EW-8 — the code's keeper, and the frozen accident (F4)

Date: 2026-08-24, session 12. Registrations: ew-design.md §EW-8
(P8-1..4, pre-run). Driver: ew8.py; data: ew8_runs.csv (500 runs,
zero exactness failures). Verdict up front: **the code can encode
its own keeper (the x-closure holds under wounds), the code's
content matters only through the description written in its
dialect, and in a mosaic the code fixes by DRIFT — selection
cannot see it, because a bad code is a commons polluter whose
damage is contagious while machinery's benefit only diffuses.**

## Setup

EW-7's table world at ring 32 (three machine species need b×10 —
the EW-6 lesson). D: b×10, w×3, x×3; keepers Ξ MORTAL and rebuilt
only by translating x. Tables: T1 = {b→Π, w→Ω, x→Ξ}, T2 = the
b/w swap with x→Ξ conserved (code maintenance universal, like
translation's core). Byte r = one table wound. 100 seeds/arm.

- **P8-1 HELD (the x-closure)**: with mortal keepers encoded in
  the description, table wounds are maintained (62/100, code at
  24.5/32, 42 repairs and 36 keeper rebuilds per run) where
  unreplaceable keepers collapse (23/100, code at 0.9/32). The
  loop "the code encodes the machine that maintains the code"
  stands on its own inside a wounded world — EW-7's immortality
  scaffolding is revoked.
- **P8-2 HELD, sharpened**: the swapped code kills every world —
  0/100, tape zero — while its machinery layer SURVIVES it
  (Π 5.8, Ω 14.7, Ξ 5.0 standing at the horizon; 96 keeper
  builds). The same description under T2 staffs the shop with
  ten translators and three copiers; law service starves, matter
  erodes, and the mis-staffed machine economy runs on over a
  dead world. D and code are co-adapted: the code's content
  matters exactly through the description written in its dialect.
- **P8-3 HELD (the frozen accident)**: the mosaic boundary drifts
  with NO directional bias — final T1 share 0.503 ± 0.109 across
  100 seeds, dead-centered on the initial 0.5. Machinery mixes
  eastward around the ring, so the bad code's cost lands on
  everyone: selection has nothing local to grip (night-11's
  commons lesson at the code level), and which code a world keeps
  is decided by drift. Crick's accident, exhibited: fixation
  without fitness.
- **P8-4 FAILED as stated — and the failure is the finding**:
  mosaic survival (13/100) is not between the pure arms near
  their average (~35); it is far below, close to pure-2.
  Mechanism: matter death is CONTAGIOUS — the under-serviced T2
  half freezes and erodes, and erosion pursues into T1 land
  (EW-3's one-handed-regrowth pursuit) — while machinery benefit
  only diffuses. Half a bad code costs much more than half: in
  this substrate, dialect pollution is super-additive, which is
  itself a selection pressure for code UNIFORMITY (any code)
  rather than code CONTENT — the strongest form of the frozen
  accident: the world cares that everyone speaks the same
  language, and drift picks which.

## Honest limits

The mosaic drift statistic is powered as registered (two
boundaries, ~50 table wounds; ±0.109 is genuine movement, mean
unbiased). The x codon is conserved across both tables by design
(a code that miscodes its own keeper is one more arm away). The
tables differ in one swap; a graded dialect-distance sweep would
turn P8-4's super-additivity into a dose curve. Machinery remains
unpriced by matter — the reason selection cannot see the code is
structural to this world and named in the registration; EW-9
supplies the missing coupling for machine-lineage traits.
